# Dicionario de dados

Este arquivo sera expandido nas proximas fases com os campos das camadas silver e gold.

## Fontes originais

- `orders.csv`: pedidos, usuarios, conjunto do pedido, numero sequencial do pedido, dia/hora e intervalo desde pedido anterior.
- `order_products__prior.csv`: itens dos pedidos historicos anteriores.
- `order_products__train.csv`: itens dos pedidos usados para treino/validacao.
- `products.csv`: cadastro de produtos.
- `aisles.csv`: corredores.
- `departments.csv`: departamentos.
